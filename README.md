# QA Fitness – Registration Form

A front-end web development project for a multi-step gym membership registration experience.

## Overview

This project demonstrates a three-step registration flow:
1. Choose a membership plan and enter personal details.
2. Browse and select a trainer.
3. View a card-entry interface with basic card-brand detection and input formatting.

## Built With

- HTML5
- CSS3
- JavaScript (vanilla)

## Project Files

| File | Purpose |
|---|---|
| `form.html` | Registration form and page structure |
| `forms.css` | Layout, styling and responsive presentation |
| `forms.js` | Step navigation, trainer selection and form interactions |
| `thankyou.html` | Completion page |

## Run Locally

1. Clone or download this repository.
2. Open `form.html` in a modern web browser.
3. Follow the registration steps.

No build tools or package installation are required.

## Important Note

This is an educational front-end demonstration. The card-entry screen does not process payments or connect to a payment provider. Do not enter real payment details.

## Learning Outcomes

- Structuring multi-step forms with HTML
- Styling a user interface with CSS
- Handling form events and DOM updates with JavaScript
- Creating interactive trainer-selection cards
- Formatting and validating user input on the client side
